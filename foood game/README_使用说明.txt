SECOND CHANCE BITES｜两关 + 无限模式

这是基于你上传的 ceremony web.zip 中 foood game 项目扩展的完整版本。
保留第一关原有素材、手势抓取、移动汤锅、暂停和结算设计；增加第二关与无限模式。

打开方式：
1. 解压文件夹，使用 VS Code 打开。
2. 右键 index.html -> Open with Live Server。
3. 第一次点击「摄像头手势开始」，允许摄像头。MediaPipe 需要联网加载。
4. 第一关：握拳抓取、张掌释放；新鲜食物进汤锅，变质食物丢到两边；达到1000分过关。
5. 抽卡动画结束后点击「进入第二关」。
6. 第二关：双臂同时伸向屏幕左侧/右侧（摄像头镜像已处理）控制汤锅接新鲜食物；坏食物和炸弹不接。
   炸弹接到扣300分；爱心每15秒出现一次，最多恢复到3条命；达到总积分1500进入无限模式。
7. 无限模式：爱心每9至26秒随机出现；直到生命耗尽；显示本机历史前10名排行榜。
8. 鼠标/触屏模式：第二关可以拖动汤锅；电脑可用 ← → 或 A/D 键控制。
9. 关卡2的 HolisticLandmarker 首次加载较慢，屏幕下方会显示加载状态；加载失败可使用方向键/鼠标。

项目文件：
index.html / style.css / script.js / level2.js / assets/*.webp

注意：
- 第二关的背景文件为 assets/camp.webp，由你本次上传的露营场景图片转换。
- 这是完整的可运行源代码，模型通过 CDN 获取，不是完全离线版本。
- 摄像头识别准确度与光线、手臂是否完整入镜有关。
- 排行榜使用浏览器 localStorage，只记录当前浏览器的历史分数，不是跨设备联网排名。
- 第一关60秒到时未达到1000分会按原代码显示时间到；需要重玩。
